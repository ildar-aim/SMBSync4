SMBSync4 Privacy Policy

Last updated: March 19, 2026

SMBSync4 is developed by ildar-aim. This privacy policy describes how the application handles user data.

1. Collected Data

1.1. Data Provided by Users

1.1.1. Data Saved by the Application

The following data is saved locally on the device within the application's private storage:

  • File information (directory names, file names)
  • SMB server information if using SMB server (host name/IP address, port number, account name*, account password*)
  • ZIP file information if using ZIP files (compression method, encryption method, encryption password*)
  • App setting options (warning messages, language and font size, etc.)
  • Application passwords*

* Sensitive data is encrypted before storage.

1.1.2. Data Not Saved

  • Passwords used to protect exported data are discarded after the operation completes and are not saved.

1.2. Execution Results

Synchronization execution results are saved to the application's private storage area so users can review them:

  • Directory names, file names, execution status
  • File sizes and modification dates of synchronized files
  • Error information

1.3. Activity Logs

When logging is enabled, activity data is stored in the app's private storage for verification and technical support. If logging is disabled, recording stops but previously recorded data is not deleted.

  • Device information (manufacturer, model, OS version, mount points, IP address, WiFi status)
  • SMBSync4 version and execution options
  • Directory names, file names, execution status
  • File sizes and modification dates
  • Debugging and error information

1.4. Sending or Writing Data Outside SMBSync4

Data held by SMBSync4 is never sent or written outside the application unless explicitly initiated by the user through:

  • Pressing the "Share" button from the History tab
  • Clicking "Send to Developer" from System Information
  • Clicking "Share" or "Send to Developer" from Log Management
  • Exporting log files from Log Management
  • Executing "Export settings" from the menu

When a password is specified for export, the attached file is password-protected. The password is discarded when the screen is closed.

2. Data Storage

All data is stored locally on the device only. SMBSync4 does not transmit any data to external servers, analytics services, or third parties.

3. Data Deletion

Uninstalling SMBSync4 deletes all saved data from the device. However, data written to external storage by user action will not be deleted.

4. Permissions

4.1. Storage

  • Android 11+: All File Access — used for file synchronization and reading/writing management files.
  • Android 10 and below: Read/Write external storage — used for file synchronization.

4.2. Network

  • View Wi-Fi connections — check network status before synchronization
  • Connect/disconnect Wi-Fi — turn WiFi on/off for scheduled synchronization (Android 8/9)
  • Full network access — synchronize via SMB protocol
  • View network connections — check connectivity

4.3. Other

  • Run at startup — initialize scheduled synchronization after device reboot
  • Control vibration — notify user when synchronization finishes
  • Prevent device from sleeping — keep device awake during synchronization
  • Install shortcuts — add sync start shortcuts to the home screen

5. Third-Party Libraries

SMBSync4 uses the following open-source libraries. These libraries do not collect or transmit user data.

  • jcifs-ng (LGPL 2.1) — SMB protocol client
  • jcifs 1.3.17 (LGPL 2.1) — SMB protocol client
  • Bouncy Castle (Bouncy Castle License) — Cryptography
  • metadata-extractor (Apache 2.0) — Photo/video metadata
  • MarkDownJ (BSD 3-Clause) — Markdown rendering
  • JcifsFile2 (MIT) — JCIFS file abstraction
  • Utilities3 (MIT) — Shared utility library
